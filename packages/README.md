# Workspace packages

This directory holds the monorepo's packages (see
[../docs/MONOREPO_MIGRATION.md](../docs/MONOREPO_MIGRATION.md)):

- `model-reaction/` — the core library
- `devtools/` — the browser DevTools extension
- `demo/` — a React app demonstrating both

The migration is complete. Each package contains its own scripts and
package-specific documentation.
